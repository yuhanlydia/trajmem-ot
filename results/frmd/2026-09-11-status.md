This is a new implementation of the supplied FRMD protocol. The fetched remote

does not assert that the originally described pilot was reproduced.

Validation: 129 tests passed; compileall and git diff --check passed. The repair
core and output-artifact fixes received an independent read-only code review.

- RTX 3090, released `perceptual-tokendrop-modul/79999`, frozen BF16 policy.

  negative/random/interpolation controls. One edit accepted, the second rejected.

  stronger on this case. It does not establish physical benefit or FRMD superiority.

  test-episode reset fingerprint checks. No policy rollout outcome is claimed.

The JSON is the machine-readable result. The initial two-step artifact predates
adding saved repaired-action arrays and per-module source hashes; the JSON losses
and actual query counts are preserved. Subsequent runs include those artifacts.

## Active follow-up

The synthetic queue covers both random and contiguous corruption, paired one-step
and two-step, centroid, and OT. All results will be retained. Actual raw pilot
source files are being prepared independently; the released raw episode seeds
match the benchmark training split, so this is development data, not an unseen
test-set generalization experiment.

Native interference concatenation, persistence, and paired physical action
branches remain separate integrations. Neither this smoke nor reset determinism
is a substitute for those experiments.

## Updated continuation policy

Per the latest research instruction, all experimental stages continue without
fixed success-gain, repair-ratio, statistical-significance, or task-count gates.
Assess positive behavior and reusability, retain negative/neutral evidence, and
continue debugging and ablations. Per-edit held-out rollback remains enabled.
