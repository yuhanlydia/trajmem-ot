# Recorded preparation scripts

These are the exact local recipes used for the recorded setup and verification,
with this run's absolute paths. They are archived for auditing, not installed CLI
entrypoints. Adjust paths and use fresh output locations when reproducing. Raw
source archives and model revisions/hashes are recorded in the adjacent dated
results directories. The RAM selector requires Linux memfd and sufficient
container RAM for the uncompressed source HDF5 plus its reserve. The original
30-episode data were processed once and reused by both memory mechanisms.
